# wifinet_solutions

Repositorio: Sitio web E-commerce para servicios de fibra y cable.

Contenido creado por la IA:

- frontend/: sitio estático (HTML + Tailwind + JS)
- frontend/assets/: imágenes (placeholders - coloca tus propias imágenes aquí), css y js
- frontend/data/plans.json: datos de los planes (usa este JSON en el frontend)
- backend/: ejemplo mínimo de Web API en C# (ASP.NET Core) con un controlador Contact
- tailwind.config.js: configuración para los colores de marca (azul, amarillo, blanco, negro)
- .gitignore

Instrucciones rápidas:

1) Sitio estático: abre `frontend/index.html` en un navegador. No requiere build porque usa Tailwind CDN.
2) Backend (opcional): desde `backend/` puedes iniciar un proyecto .NET 6+ con `dotnet run` si tienes .NET SDK instalado.

Notas:
- He dejado marcadores para imágenes en `frontend/assets/images/` con nombres como `logo.png`, `producto1.png`, `plan_familiar.png`... Sustituye por tus propias imágenes.
- Para abrir WhatsApp desde los botones, el frontend usa el número con prefijo internacional +51 (Perú). Si necesitas otro país, cambia `frontend/assets/js/main.js`.
